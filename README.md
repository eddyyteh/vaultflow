# VaultFlow

An AI-native digital asset management platform built as a professional full-stack engineering portfolio project.

## Technology Stack

- Backend: Java 21, Spring Boot
- Frontend: React, TypeScript
- Database: MySQL
- AI Integration: OpenRouter API
- Version Control: Git and GitHub
- CI/CD: GitHub Actions

## Project Status

Phase 1: Project setup and backend foundation.

## Disclaimer

VaultFlow is an educational portfolio project.
All financial balances and transactions are simulated.
